# Task: UI Módulo de Estoque
Tipo: ui
Camada: frontend
Status: ✅ Concluída

## Descrição
Criar a interface visual de inventário e estoque em `/portal/estoque`.

## Componentes
- **Inventário de Insumos:** Tabela indicando quantidade, unidade e nível crítico.
- **Inventário de Ferramental:** Tabela de equipamentos/ativos.
- **Painel de Entradas/Saídas:** Histórico e formulário manual de movimentações.
